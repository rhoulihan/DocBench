Key Insights

  • Protocol overhead dominates small operations - Oracle's ~384,436 ns fixed overhead masks OSON's JSON manipulation efficiency for typical sub-100KB updates.
  • OSON partial updates shine at scale - At 1MB+ document sizes, MongoDB's O(n) document rewrite cost exceeds Oracle's protocol overhead.
  • MongoDB's wire protocol is highly optimized - The binary BSON protocol is ~1.6x faster than JDBC/SQL for round-trips.
  • OSON wins increase with overhead removed - From 2 to 4 wins, particularly for large documents and middle-position array operations.
