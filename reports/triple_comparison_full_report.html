Summary: When to Use Each

MongoDB ($lookup)

  • Simple foreign key joins
  • Low cardinality (1:1 to 1:10)
  • Small to medium sorts (<250K)
  • Documents under 16MB
  • Simple 2-stage pipelines
  • Chained lookups

Oracle API ($sql)

  • High cardinality (1:100+)
  • Large working sets (50MB+)
  • Large sorts (500K+ docs)
  • Documents exceeding 16MB
  • Complex aggregations ($unwind, $group)
  • Memory-intensive analytics

Oracle JDBC

  • Maximum throughput scenarios
  • Server-side processing
  • Batch operations
  • Stored procedures
  • Integration with Java apps
  • When latency is critical
