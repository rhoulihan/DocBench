Hybrid Schema (JSON + Virtual Columns)

Tests a hybrid schema approach that combines JSON document storage with relational virtual columns. The hybrid tables store full JSON documents in a data JSON column, but project indexed attributes (like customer_id) into virtual/generated columns computed from JSON. This enables standard B-tree indexes on the virtual columns for efficient join predicates: JOIN ... ON c.customer_id = o.customer_id instead of JSON_VALUE(c.data, '$.customer_id') = JSON_VALUE(o.data, '$.customer_id'). The hybrid approach should match relational join performance while returning full JSON documents.
